# Moderation System

Веб-приложение для модерации объявлений: список с фильтрами и пагинацией, детальная карточка с историей модерации и действиями, статистика модератора по периодам.

## Функциональность
- Список (`/list`): фильтр по статусу/категории/цене/поиску, сортировка по дате/цене/приоритету, сброс фильтров, пагинация по 10 элементов.
- Детальная (`/item/:id`): галерея, характеристики, продавец, история модерации, кнопки «Одобрить» / «Отклонить» / «Вернуть на доработку», быстрые причины, модалки с обязательным вводом, навигация Предыдущий элемент/Следующий элемент и возврат в список.
- Статистика (`/stats`): карточки метрик за период (день, неделя, месяц), столбчатый график активности, круговая диаграмма решений, распределение по категориям.
- Прокси `/api` → сервер из папки `server`;
Состояние сортировки/фильтров сохраняется между списком и деталями.

## Использованные технологии
- React 19 + react-router-dom 7 — современный роутинг, готово к новым возможностям Suspense.
- TypeScript — типобезопасность для сущностей объявлений и статистики.
- Vite — быстрый dev/build и удобный прокси к API.
- Axios — компактные HTTP-запросы, легко расширить ретраями/отменой.
- Recharts — готовые диаграммы без ручного SVG.
- lucide-react — лёгкие иконки.
- Tailwind utility-классы — быстрый набор стилизации без отдельного UI-кита.

## Локальный запуск
Требования: Node.js 20, npm.

1) API  
```bash
cd server
npm install
npm start    # http://localhost:3001
```

2) Клиент  
```bash
cd client
npm install
npm run dev  # http://localhost:5173
```

### Сборка и предпросмотр клиента
```bash
cd client
npm run build
npm run preview
```

## Запуск через Docker Compose
```bash
docker-compose up --build
```
- Клиент: http://localhost:5173  
- API: http://localhost:3001

## Структура
- `server/` — Express API (эндпоинты объявлений, статистики, модерации).
- `client/` — фронтенд на React/TS/Vite.
- `docker-compose.yml` — совместный запуск сервер+клиент.
